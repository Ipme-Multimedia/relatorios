# Painéis de resultados · Ipme Multimédia

Publicado em https://reports.iniciativapme.pt (GitHub Pages).

- `assets/` estilo e código comuns a todos os clientes.
- Uma pasta por cliente, com um código no fim do nome para o endereço não ser fácil de adivinhar.
- Em cada pasta: `index.html` (não mexer), `dados.js` (um bloco por mês) e `img/`.
- Atualização mensal: acrescentar o mês novo no início da lista `meses` de `dados.js` e as imagens das publicações em `img/`.
- Não publicar nomes, telefones ou emails dos clientes finais (só dia, hora e número de pessoas).
